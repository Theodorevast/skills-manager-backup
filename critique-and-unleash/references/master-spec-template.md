# Master Spec & Launch Prompt Template (For Fable 5.2 / Long-Horizon Agents)

Use this structure when generating the standalone rebuild specification in **Phase 3**. Adapt domain specifics (3D Three.js game, interactive canvas tool, full-stack web app) while keeping all four structural pillars intact.

---

## Pillar 1: Document Template (`CLAUDE_<TIMEBOX>_MASTER_GUIDE.md`)

```markdown
# 致 Claude (Fable 5.2)：`<旧入口>` 深度复盘批判与 <N> 小时高标准重构军令状

> **任务定位**：在 **<N> 小时** 内，于全新独立工程目录 `<新目录绝对路径>`（固定端口 `http://127.0.0.1:<PortB>`）从零构建达到行业 Showcase 水准的 **《<项目名>》**。
> **战场隔离铁律**：严禁修改 `<旧目录绝对路径>`（`<PortA>` 保留作为反面基线进行同台实机对比，仅允许只读复用其中指定的合格资产或认证凭证）。

## 第一部分：前车之鉴 —— 原版实机审计查实的硬伤禁令（严禁重犯）
1. **交付定性落差**：[列出概念承诺 vs 实际代码行数/缺失闭环的对比数据]
2. **资产与架构反模式**：[列出错误使用外部生成模型、缺少合批/实例化、压缩失真等具体病灶与行号]
3. **逻辑/坐标/视觉穿帮**：[列出算术错误、悬空元素、雾效/边界断层、无碰撞等实机截图证据]
4. **性能瓶颈与虚假监控**：[列出实测真实帧率、最大耗时 Pass，以及原统计代码的口径 Bug]

## 第二部分：新作总纲与黄金分工契约
- **工程与端口**：`<新目录>`，固定绑定 `127.0.0.1:<PortB>`。
- **资产与代码黄金分工**：
  - 外部生成资产仅限：[明确仅用于哪些有机角色/特殊图标，规定统一骨骼/接口规范、无损法线贴图格式，以及程序化兜底策略防队列阻塞]。
  - 100% 纯代码与 Shader 编译：[明确建筑/布局、多通道 PBR 纹理、反射光学、物理交互、动态声景的范围]。
- **核心空间/模块规格**：[用清晰表格定义世界卡带/核心视图、主角状态、标志性交互]。

## 第三部分：核心系统工程契约（定边界与效果标准，不写死碎步伪代码）
1. **核心操控与状态切换**：[输入映射、碰撞解算、镜头物理反馈]
2. **角色/主体动态表现**：[基础动画速率对齐 + 运行时代码 IK / 弹簧物理叠加 + 高潮状态反馈]
3. **大规模动态元素性能方案**：[`InstancedMesh` / 静态按材质合批 / 空间哈希解算]
4. **光学、材质与声景细节**：[局部平面反射/粗糙度遮罩、假三维视差、接地软阴影、WebAudio 实时合成]
5. **核心循环与 HUD**：[限时高潮机制 / 自由模式、关键状态可视化、移动端安全区适配]

## 第四部分：硬性性能红线与四阶段真机自检铁笼
- **真实诊断探针 (`window.__diag`)**：必须关闭自动重置，用独立墙钟 `performance.now()` 计算真实 FPS，暴露真实整帧 `calls`、`triangles`/DOM 节点数与帧耗时。
- **硬指标底线**：目标硬件真实 GPU 浏览器下稳定 `>= 60 FPS`，整帧 `Draw Calls <= <上限>`，零控制台报错。
- **四阶段里程碑与强制 Playwright GPU 截图自检**：
  - 阶段 1（0 ~ 25% 时间）：核心骨架、物理手感与性能探针（跑满 60 FPS 方可推进）
  - 阶段 2（25% ~ 55% 时间）：光学渲染底座 + 首个标杆模块打磨至 95 分（多机位截图严查穿帮）
  - 阶段 3（55% ~ 80% 时间）：扩展模块/卡带接入 + 核心必杀机制与无缝流转
  - 阶段 4（80% ~ 100% 时间）：完整循环、合成声景、HUD 与全场景 GPU 压力验收报告
```

## Pillar 2: Copy-Paste Launch Prompt Template

Give the user a clean text block they can paste directly into a fresh Fable 5.2 session (recommend `high` / `xhigh` effort):

```text
请先完整阅读 `<CLAUDE_MASTER_GUIDE 绝对路径>`，这是对原项目实机审计的硬伤复盘，以及接下来 <N> 小时重构开发的完整技术与美学规范。

执行要求：
1. 严格目录与端口隔离：
   - 严禁修改 `<旧目录>` 中的任何文件（`<PortA>` 保留作为反面教材同台对比，仅可只读拷贝文档中允许的现成资源）。
   - 在 `<新目录>` 独立建项，开发服务器固定绑定 `http://127.0.0.1:<PortB>`。

2. 全程自主闭环推进，严禁半途停工或交付 Look-Test 空壳：
   - 你拥有完整的 <N> 小时开发预算。不要每做完一步就停下来询问“是否继续”，严禁省略核心交互闭环或用简陋占位符敷衍。
   - 严格执行文档中的「黄金分工原则」与性能红线。

3. 强制真实 GPU 浏览器多视角自检门禁：
   - 每完成一个阶段，必须用硬件加速的 Playwright（`channel: 'chrome'`，开启 `--use-angle=metal --enable-gpu --ignore-gpu-blocklist`）打开 `http://127.0.0.1:<PortB>` 截取默认视角、全局俯视穿帮检查图、近景材质细节图与核心交互状态图，并亲自查看截图修完所有穿帮后再进入下一阶段。
   - 暴露真实整帧监控 `window.__diag`（用真实墙钟算 FPS，关闭渲染计数自动清零），确保全程稳定 `>= 60 FPS`、零报错、达到 Showcase 级水准后再向我汇报最终成果。现在直接开始第 1 阶段！
```
